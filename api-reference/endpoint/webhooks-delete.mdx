---
title: "Remover Webhook"
icon: "bolt"
openapi: "DELETE /webhooks/{name}"
---

Remove permanentemente um webhook pelo nome. O webhook para de receber eventos imediatamente.

### Path

<Warning>
  A exclusão é permanente. Para pausar temporariamente sem perder a configuração, use o [toggle](/api-reference/endpoint/webhooks-toggle) com `active: false`.
</Warning>
