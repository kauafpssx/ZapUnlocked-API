---
title: 'Verificar Status'
icon: "heart-pulse"
openapi: "GET /status"
---

Retorna o status completo da API: uptime, métricas do processo, sistema, runtime e estado de conexão do WhatsApp.

### Campos

| Campo | Tipo | Descrição |
|---|---|---|
| `status` | `string` | `ok` se WhatsApp conectado, `degraded` se desconectado |
| `uptime` | `string` | Uptime formatado (ex: `2d 3h 45m 12s`) |
| `uptime_seconds` | `integer` | Uptime em segundos |
| `whatsapp.connected` | `boolean` | Se o WhatsApp está autenticado |
| `whatsapp.qr_pending` | `boolean` | Se há QR Code aguardando escaneamento |
| `process.cpu_percent` | `float` | CPU do processo desde a última chamada |
| `process.memory_rss` | `string` | Memória física usada pelo processo |
| `system.cpu_percent` | `float` | CPU total do sistema |
| `system.disk_percent` | `float` | Uso de disco em % |
| `runtime.python` | `string` | Versão do Python |
