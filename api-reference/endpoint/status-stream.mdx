title: 'Stream de Status'
icon: "heart-pulse"
openapi: "GET /status/stream"
---

Retorna um stream **Server-Sent Events (SSE)** com o status de conexão em tempo real e o QR Code. Útil para monitorar a sessão e exibir o QR Code dinamicamente sem polling.

<Note>
  A conexão permanece aberta. O servidor envia um evento a cada poucos segundos com o estado atual. Quando o WhatsApp conecta, o QR Code desaparece e `connected` vira `true`.
</Note>

### Resposta (evento SSE)

Cada evento é um objeto JSON no campo `data:`:

### Campos

| Campo | Tipo | Descrição |
|---|---|---|
| `connected` | `boolean` | Se o WhatsApp está autenticado |
| `qr` | `string \| null` | QR Code como imagem PNG em Base64, ou `null` se já conectado |
| `timestamp` | `string` | Timestamp UTC do evento |
